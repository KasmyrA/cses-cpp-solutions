# CSES C++ Solutions

Handwritten C++ solutions for the [CSES Problem Set](https://cses.fi/problemset/).

Solutions are stored in the same order as the official task list. Problem statements are not copied into this repository; use the official CSES links in `TASKS.md`.

## Structure

- `01-introductory-problems/`
- `02-sorting-and-searching/`
- `03-dynamic-programming/`
- `04-graph-algorithms/`
- `05-range-queries/`
- `06-tree-algorithms/`
- `07-mathematics/`
- `08-string-algorithms/`
- `09-geometry/`
- `10-advanced-techniques/`
- `11-sliding-window-problems/`
- `12-interactive-problems/`
- `13-bitwise-operations/`
- `14-construction-problems/`
- `15-advanced-graph-problems/`
- `16-counting-problems/`
- `17-additional-problems-i/`
- `18-additional-problems-ii/`

The official task list currently contains 406 tasks. The order and names are recorded in `TASKS.md` and should be treated as the source for solution numbering.

## File naming

```text
01-introductory-problems/001-weird-algorithm.cpp
01-introductory-problems/002-missing-number.cpp
02-sorting-and-searching/025-distinct-numbers.cpp
```

Each solution should preferably contain a short explanation, algorithm, complexity, and implementation.
