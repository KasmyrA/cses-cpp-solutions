# CSES C++ Solutions

This repository contains handwritten C++ solutions for the CSES Problem Set.

The solutions are organized by CSES problem number in ascending order, so each file corresponds to a specific problem.

## Repository structure

```text
.
├── README.md
├── .gitignore
├── templates/
│   └── problem_template.cpp
├── solutions/
│   ├── README.md
│   └── 001_weird_algorithm.cpp
└── ...
```

## Naming convention

Use the following pattern for solutions:

```text
solutions/001_weird_algorithm.cpp
solutions/002_missing_number.cpp
solutions/003_repetitions.cpp
```

For each file, include:
- problem number and title
- short explanation or intuition
- algorithm
- complexity
- the final C++ implementation

## CSES link

https://cses.fi/problemset/

## Notes

- solutions are written manually
- focus is on correctness and clarity
- every file should be compilable with a standard C++ compiler
