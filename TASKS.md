# Task list

The official CSES task list is available at:

- https://cses.fi/problemset

The repository follows the official order and uses a global number for every task. For example:

```text
001 Weird Algorithm
002 Missing Number
003 Repetitions
...
024 Grid Path Description
025 Distinct Numbers
```

Problem statements are intentionally not duplicated here. CSES publishes its problem set under **CC BY-NC-SA 4.0**, while this repository's source code is MIT-licensed. Keeping links instead of copying statements avoids mixing those licenses and keeps the repository focused on original solutions.
